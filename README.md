# Hybrid Search Engine 🚀

A powerful **Hybrid Search Engine** that combines keyword-based (lexical) search and semantic (vector) search to deliver highly accurate and context-aware results.

This system is designed to handle marathi government by integrating **ElasticSearch** for fast text search and **Semantic Search** for meaning-based retrieval using **SBERT** models.

---

## ✨ Key Features

- 🔍 Lexical Search using ElasticSearch  
- 🧠 Semantic Search using vector embeddings  
- 🔄 Automated data scraping, cleaning, and preprocessing  
- 🌐 Multilingual support (English & Marathi)  
- ⚡ Hybrid ranking combining keyword relevance and semantic similarity  

---

## 🛠️ Tech Stack

- Python  
- ElasticSearch
- Transformers
- mahaSBERT, indicSBERT
- Pandas, NLP tools  

---

## 🔁 How It Works

1. Scrapes raw data from government/public sources  
2. Cleans and preprocesses the data  
3. Translates content into multiple languages  
4. Indexes data into ElasticSearch (lexical search)  
5. Generates vectors and stores them for semantic search  
6. Combines both results to produce hybrid-ranked search output
